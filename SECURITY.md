# Security Policy

## Reporting Security Issues

If you discover any security vulnerabilities or potential risks:
- **Do not open a public issue.**
- Please report vulnerabilities directly to the maintainers via email or private GitHub advisory.

## Security Best Practices
- Never commit `.env` files or API keys into git.
- The project includes `.env` in `.gitignore` by default.
- This application does not store Steam passwords, Steam Guard tokens, or private login cookies.
